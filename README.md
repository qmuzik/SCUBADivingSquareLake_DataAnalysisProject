# SCUBADivingSquareLake_DataAnalysisProject

Personal Project for Portfolio Website. 

This project was for my portfolio website, SCUBA Q Multimedia. Here is the link to my portfolio: https://quincymuzik0116.wixsite.com/scuba-q-multimedia 

For this project, I used Python 3.13 and the following libraries/modules to analyze my SCUBA Dives conducted in Square Lake:
- Matplotlib
- Pandas

I used a dataset that I created called DiveLog.csv, which contains all of the dives I've done in Square Lake. Each dive includes the following columns: 
- Dive Number
- Date
- Location
- Dive Site
- Time In
- Bottom Time
- Max Depth
- Visibility
- Water Temp (F)
- Weight

This project established the relationship/trend between the Dive Number and other columns.
